# Movie Picker – projekto idėja

## 1. Projekto aprašymas
Movie Picker – internetinė aplikacija, padedanti vartotojui greitai išsirinkti filmą pagal žanrą ir nuotaiką.

## 2. Sprendžiama problema
Žmonės dažnai sugaišta daug laiko ieškodami tinkamo filmo. Aplikacija padeda supaprastinti šį pasirinkimą.

## 3. Tikslinė auditorija
Filmų mėgėjai, norintys greitai rasti filmą vakarui.

## 4. Kaip problema sprendžiama dabar?
Vartotojai naršo filmų platformose, skaito rekomendacijas arba klausia draugų.

## 5. Pagrindinės funkcijos
- Filmų pasirinkimas pagal žanrą.
- Filmų pasirinkimas pagal nuotaiką.
- Atsitiktinė filmo rekomendacija.
- Patikusių filmų išsaugojimas.

## 6. Pagrindinė vartotojo užduotis
Pasirinkti žanrą arba nuotaiką, paspausti „Pasiūlyk filmą“ ir gauti rekomendaciją.

## 7. Duomenys
Naudosime savo sudarytą 20–30 filmų sąrašą, saugomą Supabase duomenų bazėje. Išorinio filmų API nenaudosime.

## 8. Technologijos
JavaScript, React, Vite, CSS, Supabase ir GitHub.

## 9. Projekto tikslas
Sukurti paprastą, patogią ir vizualiai patrauklią filmų rekomendavimo aplikaciją.
